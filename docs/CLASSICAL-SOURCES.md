# 古典角色取材記錄

查閱日期：2026-09-21。此表為《山海弈》原創角色改編的取材依據，按古典作品分組；章回連結供核對。內容均作簡短轉述，未使用現代影視或遊戲的角色造型作範本。

## 一、《史記》：上古傳說與歷史人物須分開

| 角色 | 取材與可用意象 | 原文位置 |
| --- | --- | --- |
| 黃帝 | 上古傳說中的軒轅。文本記其與蚩尤戰於涿鹿、統合諸侯、以雲命官及土德之瑞，可取雲紋、土色、統御意象。這是古書所載的傳說敘事，不能把神異細節標示為已考證史實。 | [卷一・五帝本紀](https://zh.wikisource.org/wiki/史記/卷001) |
| 孔子 | 歷史上的孔丘、字仲尼，出自魯國。此傳記述問禮、授徒與周遊經歷，可取師者、禮儀、求學意象；遊戲法術和戰鬥技能屬原創演繹。 | [卷四十七・孔子世家](https://zh.wikisource.org/wiki/史記/卷047) |

## 二、《西遊記》：神話與小說形象

| 角色 | 取材與可用意象 | 原文位置 |
| --- | --- | --- |
| 盤古 | 創世神話人物。開篇以盤古破除混沌、天地清濁分開引入世界，可取天地分界、雲氣與山石。此處是後世小說承接既有傳說，並非宣稱盤古最早出自《西遊記》；本次查閱未核實開天斧的早期文獻來源。 | [第一回](https://zh.wikisource.org/wiki/西遊記/第001回) |
| 孫悟空 | 神魔小說人物。第四回明寫金冠、金甲、步雲鞋、如意金箍棒，以及齊天大聖旗號，可作辨識意象。 | [第四回](https://zh.wikisource.org/wiki/西遊記/第004回) |
| 哪吒 | 神話人物，本次另核對《西遊記》中的李靖三太子形象：年輕天將，戰時現三頭六臂，兵器包含火輪。該章的六件兵器組合不等同其他作品的哪吒設定，設計時不混稱為唯一原典造型。 | [第四回](https://zh.wikisource.org/wiki/西遊記/第004回) |

## 三、《紅樓夢》：小說人物

| 角色 | 取材與可用意象 | 原文位置 |
| --- | --- | --- |
| 林黛玉 | 第三回寫她入賈府時細心觀察、言行謹慎，也提及讀書；外貌清秀、身體纖弱。可取文氣與敏銳心思。此章不作葬花情節的引證。 | [第三回](https://zh.wikisource.org/zh-hant/紅樓夢/第003回) |
| 王熙鳳 | 第三回以華麗紅金服飾、鳳形珠釵與鮮明的言談氣勢登場。可取鳳釵、紅金配色、主持事務的自信神情。 | [第三回](https://zh.wikisource.org/zh-hant/紅樓夢/第003回) |

## 四、《三國演義》：採小說演繹，不把小說當史實

| 角色 | 取材與可用意象 | 原文位置 |
| --- | --- | --- |
| 關羽 | 有歷史原型，本卡採小說武將形象。第一回明寫打造青龍偃月刀，可作長柄刀意象；不能据此宣稱歷史關羽實際使用該刀。 | [第一回](https://zh.wikisource.org/wiki/三國演義/第001回) |
| 諸葛亮 | 有歷史原型，本卡採小說中的草廬賢士、三顧與隆中論策意象。謀略型技能屬遊戲改編。 | [第三十八回](https://zh.wikisource.org/zh-hant/三國演義/第038回) |
| 貂蟬 | 本卡定位為小說虛構人物。第八回寫她是王允府中歌伎，受訓歌舞並參與連環計；可取歌舞、機敏、庭園場景。不將其故事當作已證實的歷史人物傳記。 | [第八回](https://zh.wikisource.org/wiki/三國演義/第008回) |

## 六、《封神演義》：哪吒卡牌採用的主要意象

補核對 [第十四回・哪吒現蓮花化身](https://zh.wikisource.org/wiki/封神演義/卷014)：太乙真人以荷葉與蓮花重造哪吒，傳授火尖槍與風火輪，並交予乾坤圈、混天綾等法寶。因此本卡以「封神演義」作出處標籤，蓮火、金圈與紅綾為其識別意象；服裝與構圖由本作重新設計。

所有卡牌數值、陣營、技能、配色延伸和畫面構圖均由本專案設計。此表核對人物歸屬與少量文本意象，不代表復原古人容貌、考證服飾年代或全面整理各版本傳說。
